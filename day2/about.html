About QuickNotes

QuickNotes is a simple app for capturing short notes, reminders and ideas the moment they occur to you. It is designed to stay out of your way, so you can write first and organise later.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and the text of your note.
  3. Save the note; it appears in your notes list.
  4. Click any note in the list to edit or delete it.

Features

  • Instant note creation
  • Search across all your notes
  • Simple, distraction-free editor
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
